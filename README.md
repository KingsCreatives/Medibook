# MediBook: Streamlining Healthcare Appointments

![Medibook demo](/public/assets/gifs/demo.gif)

MediBook is a comprehensive appointment management platform designed to simplify the healthcare booking process for both patients and administrators. With its user-friendly interface and robust features, MediBook enhances the efficiency and convenience of healthcare scheduling.

## Core Features

* **Patient Registration:** Users can easily create secure profiles to manage their health appointments.
* **Appointment Booking:** Patients can effortlessly schedule appointments with their preferred doctors, and even manage multiple bookings.
* **Admin Appointment Management:** Administrators have a centralized dashboard to oversee and handle all scheduled appointments efficiently.
* **Appointment Confirmation/Scheduling:** Admins can confirm and adjust appointment times to optimize schedules.
* **Appointment Cancellation:** Administrators can cancel appointments when necessary.
* **SMS Notifications:** Patients receive timely SMS confirmations upon successful appointment bookings.
* **Complete Responsiveness:** MediBook provides a seamless experience across all devices and screen sizes.
* **Secure File Storage:** Patients and administrators can upload and store files securely using Appwrite's robust storage services.
* **Performance Monitoring:** MediBook leverages Sentry to track application performance and identify potential issues for proactive resolution.

## Technical Highlights

* **Next.js:** The frontend is built with Next.js, providing server-side rendering, optimized performance, and improved SEO.
* **Appwrite:** Appwrite powers the backend, offering a comprehensive set of APIs for user authentication, database management, file storage, and more.
* **TypeScript:** The codebase is written in TypeScript, ensuring type safety and enhancing code maintainability.
* **Tailwind CSS & ShadCN:** The UI is styled using Tailwind CSS with ShadCN components, resulting in a clean and modern design.
* **Twilio:** Twilio enables the seamless integration of SMS notifications for appointment confirmations.

## Additional Strengths

* **Clean Code Architecture:** The project emphasizes a well-structured codebase with reusable components, promoting scalability and maintainability.
